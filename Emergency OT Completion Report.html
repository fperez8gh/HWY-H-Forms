How to Use — Emergency OT Completion Report

  1. Complete the report information. Fill in the memo/report fields and employee information as applicable.
  2. Enter each employee’s overtime. Complete the available employee, position, date, start-time, end-time, and CTO/Cash fields. Use the entry controls to add or remove entries as needed.
  3. Review the report. Check all names, dates, times, and narrative fields before printing or saving.
  4. Print / Save PDF opens the browser’s print window. Choose a printer or “Save as PDF.”
  5. Save EOT saves a working EOT data file. Use Open EOT to reopen a previously saved EOT file.
  6. Import / Export lets you import information from an Excel workbook or export the current report to XLSX.
  7. Reset All Entries clears the current entries. Use it only when you intend to start over.

Tip: Save your EOT file before closing the page. Excel import/export may require an internet connection to load its supporting library.
