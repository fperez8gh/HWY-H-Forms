How to Use — Planned OT Completion Report

  1. Enter a date for each planned overtime entry. The Pay Period is determined automatically from the latest valid entry date.
  2. Enter the start and end times. Hours are calculated automatically; describe the work to be performed in the Description of Work field.
  3. Use + Add Entry to add rows as needed. Review the dates, times, hours, and descriptions before printing.
  4. Use Print / Save PDF to build the report as a PDF and open it in a new tab; print or save it from there. On iPhone/iPad, tap Share → Print in the PDF view. Printing the PDF (rather than this web page) keeps the browser’s header and file-location footer off the report, and multi-page reports show each page’s subtotal with the overall total on the last page.
  5. Use Download PDF to save the report as a PDF. The PDF carries the entries inside it, so it doubles as your save file.
  6. Use Open PDF & Continue Filling to reopen a PDF made by this page and continue editing it. A copy re-saved through a print driver (for example, Microsoft Print to PDF) does not keep the entries, so keep the downloaded file itself.
  7. Use Import / Export to import or export an Excel workbook. Excel functions require the Excel library to load.
  8. Reset All Entries clears the current report. Save your work first if you may need it later.
