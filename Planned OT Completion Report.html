How to Use — Planned OT Completion Report

  1. Enter a date for each planned overtime entry. The Pay Period is determined automatically from the latest valid entry date.
  2. Enter the start and end times. Hours are calculated automatically; describe the work to be performed in the Description of Work field.
  3. Use + Add Entry to add rows as needed. Review the dates, times, hours, and descriptions before printing.
  4. Use Print / Save PDF to print or save the report as a PDF.
  5. Use Save Planned OT to save an editable .pot file, and Open Planned OT to reopen one.
  6. Use Import / Export to import or export an Excel workbook. Excel functions require the Excel library to load.
  7. Reset All Entries clears the current report. Save your work first if you may need it later.
